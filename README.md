Rudimentary VB.NET project simulating a printer for the HP3000 SIMH simulator.

This software expects to have a serial printer configured on a "serial" port that is capable of listening on a TCP/IP port.

This project is experimental, comments and suggestions are appreciated.
The greenbar jpg was generated as a blank page using racingmar's virtual1403 for hercules, which is also available here on github.
